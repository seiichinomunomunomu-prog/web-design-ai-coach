# WEB Design AI Coach

## 概要

HTML・CSSコードを入力すると、AIがコードレビュー・改善提案を行うWebアプリケーションです。

対象

- Webデザイン初学者
- HTML/CSS学習者
- ポートフォリオ作成中の方

---

# 開発環境

- Python 3.14
- FastAPI
- Uvicorn
- Jinja2
- HTML5
- CSS3
- VS Code
- Dify（予定）
- Render（予定）

# 開発再開手順

① VS Code起動

② web-design-AI-coach を開く

③ ターミナル

```
cd app
```

④

```
.\.venv\Scripts\Activate.ps1
```

⑤

```
py -m uvicorn main:app --reload
```

⑥

ブラウザ

```
http://127.0.0.1:8000
```
