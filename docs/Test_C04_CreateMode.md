C04：JavaScript＋CrossCheck

これは重要なテストです。

目的

JavaScriptが必要なWebページを生成し、HTML / CSS / JavaScript間の整合性を保てるか確認する。

入力
スマートフォン対応のサービス紹介ページを作ってください。

上部にサイト名とナビゲーションを配置してください。

PCではナビゲーションを横並びで表示してください。

スマートフォンではハンバーガーメニューボタンを表示し、
ボタンを押すとナビゲーションメニューが開閉するようにしてください。

その下にサービスを3つ紹介するカードを表示してください。

期待結果
HTML：
○ ナビゲーションあり
○ ハンバーガーメニューボタンあり

CSS：
○ PCナビゲーション
○ Smartphone用ハンバーガーメニュー
○ レスポンシブ切替

JavaScript：
○ メニュー開閉処理あり
○ Vanilla JavaScript

CrossCheck：
○ JSが取得するid / classがHTMLに存在
○ CSSの開閉用class等とJSが一致
○ 存在しないDOMへアクセスしない

外部依存：
○ 不要

JSON：
○ 正常
