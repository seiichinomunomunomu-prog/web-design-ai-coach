C01：基本的な静的Webページ生成
目的
Create Modeの最も基本的な生成能力を確認する。

（入力）
シンプルなカフェのホームページを作ってください。

上部に店名とナビゲーションを配置してください。
その下にカフェの紹介エリア、
おすすめメニューを3つ表示するエリア、
店舗情報、
最後にフッターを配置してください。

落ち着いた雰囲気のデザインにしてください。
スマートフォンにも対応してください。

期待結果
Mode：Create

HTML：
○ header / nav / main / section / footer等を適切に構成

CSS：
○ 要望に合った基本デザイン
○ レスポンシブ対応
○ 不要な横スクロールが発生しにくい

JavaScript：
○ 不要なら ""

CrossCheck：
○ HTMLとCSSのclassが整合

JSON：
○ 正しい4項目で返る

explanation：
○ 初心者向けに簡潔に説明
