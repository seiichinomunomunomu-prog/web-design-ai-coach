# Learning Note

## FastAPIとは

ブラウザからリクエストを受け取り、

処理を行い、

結果を返すWebアプリケーションフレームワーク。

---

## Uvicornとは

FastAPIを動かすWebサーバー。

起動中だけ

```
http://127.0.0.1:8000
```

へアクセスできる。

停止すると接続できなくなる。

---

## Webサーバーとは

現在

```
VS Code

↓

main.py

↓

Uvicorn

↓

127.0.0.1:8000
```

将来

```
Render

↓

FastAPI

↓

https://xxxxx.onrender.com
```

になる。

---

## Jinja2とは

FastAPIからHTMLへデータを渡すテンプレートエンジン。

今後

```
AIレビュー

↓

Jinja2

↓

HTML表示
```

になる。

---

## StaticFiles

FastAPIでは

```
/static
```

というURLを公開する。

HTMLから

```
/static/css/style.css
```

と書けば

```
app/static/css/style.css
```

を読み込める。

---

.\.venv\Scripts\Activate.ps1
```

が必要。

(.venv)

が表示されたら有効。

```
/static/css/style.css
```

を使用。

```
../static

## スペースキー不具合

確認事項

- HP EliteBook 830 G8
- スペースキーのみ暴走
